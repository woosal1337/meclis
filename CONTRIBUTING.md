# Contributing to meclis

Thanks for the interest. `meclis` is small and intentionally opinionated, but the surface that benefits most from contributions — new advisors, sprites, themes, and Phase B (mid-turn streaming) — is wide open.

## Getting set up

```bash
git clone git@github.com:woosal1337/meclis.git
cd meclis
bun install
bun run dev:server          # in one terminal
bun run dev:web             # in another
bun run install-hooks       # once
```

If you've never set up Claude Code hooks before, the [Quickstart in the README](README.md#quickstart) is the canonical path.

## What we welcome

### New advisor packs

The most valuable kind of contribution. The agora ([`collection/`](collection/)) is the canonical home for community-shipped character packs. Every merged advisor appears at <https://meclis.chele.bi> and becomes installable via `bunx @meclis/cli add <slug>` within a deploy.

Open a PR with a new folder under `collection/<slug>/`:

| File | Required | Notes |
| --- | --- | --- |
| `advisor.md` | yes | The character pack. H1 must equal `displayName`. |
| `advisor.json` | yes | Validated against [`collection/_schema/advisor.schema.json`](collection/_schema/advisor.schema.json). |
| `sprite.png` | yes | 896×1200, transparent background, ~93% canvas fill. |
| `sprite.thumb.png` | yes | Generated by `bun run generate-thumbs`. |
| `references.md` | optional | Bibliography of distilled sources. |

CI rejects PRs that violate the schema, sprite dimensions, slug-folder match, or H1-displayName match. The full authoring guide is at [`docs/authoring-advisors.md`](docs/authoring-advisors.md).

The bar is "enough public material to build a tight pack of someone's voice." Living thinkers who would loathe the project on principle deserve restraint — meclis is a personal-use tool, but the agora is public.

### Sprites in matching style

The reference sprites are 896×1200 PNGs with transparent backgrounds and ~93% canvas fill. Style: detailed pixel-art proportions, matching the existing cast. [`scripts/generate-sprites.md`](scripts/generate-sprites.md) has the Gemini Nano Banana Pro prompt template the existing sprites were built from.

### Alternative themes

Current theme is "ancient Greek symposium". The architecture supports swapping background, palette, and bubble styling — Renaissance court, Edo-period tea house, contemporary boardroom. PRs that introduce a `themes/` switch are welcome.

### Phase B — mid-turn streaming

Today the speech bubble fills only after `PostToolUse` fires. A more lifelike experience would stream tokens as the sub-agent writes them, by tailing the Claude Code session jsonl at `~/.claude/projects/<project>/<session>.jsonl`. The shape of the events is already defined (`speech_delta`, `thinking_delta` in `packages/shared/src/events.ts`); the tailer is the missing piece.

## Code style

- TypeScript strict mode. No `any` without an explicit reason.
- No comments. Names should carry the meaning. The only acceptable comments are tooling directives (`@ts-ignore`, `eslint-disable`).
- Two-space indent, single quotes.
- Run `bun run typecheck` before pushing. CI will reject diffs that don't typecheck.
- For collection PRs: `bun run validate-collection` before pushing.

## Commits

Conventional commit shape, lowercase, present tense, under 70 chars on the subject line:

```
feat(web): focus the most recent speaker by default
fix(server): drain pending events when an advisor joins late
docs(readme): clarify how to add a new advisor
feat(collection): add marcus-aurelius
```

PRs that touch user-visible behavior should include a screenshot or short clip of the change.

## Reporting bugs

Open a GitHub issue with:
- Your OS + Bun version (`bun --version`) and Node version (`node -v`)
- A reproduction (the `/meclis` invocation that triggered the bug, or a `curl` that synthesizes the same event)
- What you saw vs. what you expected
- Any output from running the hook with `MECLIS_DEBUG=1`

## Code of conduct

Be kind. Disagree about ideas, not people. The goal is a useful tool, not a winning argument.
